### Компиляция и запуск на Linux

#### Предварительные требования для Debian/Ubuntu

Для Ubuntu 22.04:
`sudo add-apt-repository ppa:dotnet/backports`

Для Debian или других конфигураций:

```
wget https://packages.microsoft.com/config/debian/12/packages-microsoft-prod.deb -O packages-microsoft-prod.deb
sudo dpkg -i packages-microsoft-prod.deb
rm packages-microsoft-prod.deb
```

Продолжите установку:

`sudo apt-get update && sudo apt-get install -y dotnet-sdk-10.0`

#### Получение Basis

Перейдите в нужную папку и выполните:

`git clone -b long-term-support-20260425 https://github.com/BasisVR/Basis`

#### Сборка сервера Basis

Откройте терминал и перейдите в директорию: `cd Basis/Basis\ Server`

`dotnet restore`

Выполните сборку:

`dotnet build` (для отладки)

или

`dotnet build --configuration Release` (для релиза)

#### Выполнение

Перейдите в директорию BasisServerConsole и запустите:

`dotnet .\BasisNetworkConsole.dll`

:::tip Для специализированного Linux-релиза

`dotnet publish -f net10.0 --self-contained --os Linux`

Из `BasisServerConsole/bin/Debug/net10.0/BasisNetworkConsole` запустите `./BasisNetworkConsole`.

:::

## Файлы конфигурации

При первом запуске сервера в каталоге с exe-файлом создаются различные конфигурационные файлы.

| Файл/Папка               | Описание                                    |
|--------------------------|---------------------------------------------|
| `config.xml`             | Основной конфигурационный файл сервера.     |
| `initialresources/`      | Содержит файлы миров и объектов для загрузки по запросу. |
| `Log/`                   | Папка с логами сервера.                     |
| `admins.xml`             | Список пользователей с правами администратора. |
| `banned_players.xml`     | Список заблокированных аккаунтов игроков.   |

## Config.xml

| Переменная | По умолчанию | Описание |
|---|---|---|
| `PeerLimit` | 65535 | Максимальное число подключённых peers. |
| `SetPort` | 4296 | UDP-порт, на котором слушает сервер. |
| `UseNativeSockets` | true | Использует нативные socket-вызовы ОС вместо managed-пути. |
| `NatPunchEnabled` | false | Включает NAT punch-through для знакомства peers. |
| `PingInterval` | 1500 | Интервал keep-alive ping, в миллисекундах. |
| `DisconnectTimeout` | 30000 | Время без ответа до отключения peer, в миллисекундах. |
| `SimulatePacketLoss` | false | Искусственно отбрасывает исходящие пакеты для тестов. |
| `SimulateLatency` | false | Искусственно задерживает пакеты для тестов. |
| `SimulationPacketLossChance` | 10 | Процент потери пакетов при включённой симуляции. |
| `SimulationMinLatency` | 50 | Минимальная добавленная задержка, в миллисекундах. |
| `SimulationMaxLatency` | 150 | Максимальная добавленная задержка, в миллисекундах. |
| `ReconnectDelay` | 500 | Время перед попыткой переподключения. |
| `MaxConnectAttempts` | 10 | Максимальное число попыток подключения. |
| `ReuseAddresss` | false | Опция повторного использования socket; обратите внимание на написание поля. |
| `DontRoute` | false | Опция маршрутизации socket. |
| `EnableStatistics` | true | Собирает транспортную статистику для health/status отчётов. |
| `IPv6Enabled` | true | Включает поддержку IPv6 dual-stack socket. |
| `MtuOverride` | 0 | Принудительно задаёт MTU; 0 отключает переопределение. |
| `MtuDiscovery` | true | Включает Path-MTU discovery. |
| `DisconnectOnUnreachable` | false | Отключает при ICMP unreachable. |
| `AllowPeerAddressChange` | true | Разрешает endpoint peer изменяться во время сессии. |
| `HasFileSupport` | true | Разрешает запись логов, списков модерации, auth-идентичности и других данных на диск. |
| `HealthCheckHost` | localhost | Host или интерфейс для health checks. Используйте * для всех интерфейсов. |
| `HealthCheckPort` | 10666 | TCP-порт для health checks. |
| `HealthPath` | /health | Путь endpoint health check. |
| `BSRSMillisecondDefaultInterval` | 50 | Базовый интервал отправки Server Reduction System, в миллисекундах. |
| `BSRBaseMultiplier` | 1 | Базовый множитель перед масштабированием по расстоянию. |
| `BSRSIncreaseRate` | 0.005 | Как быстро интервалы отправки растут с расстоянием. |
| `BSRSlowestSendRate` | 2.55 | Самая медленная частота отправки для удалённых peers. |
| `HighQualityDistance` | 3 | Порог расстояния для синхронизации avatar высокого качества. |
| `MediumQualityDistance` | 10 | Порог расстояния для синхронизации avatar среднего качества. |
| `LowQualityDistance` | 20 | Порог расстояния для синхронизации avatar низкого качества. |
| `OverrideAutoDiscoveryOfIpv` | false | Привязывает ровно настроенные адреса вместо автоопределения версии IP. |
| `IPv4Address` | 0.0.0.0 | IPv4-адрес привязки. |
| `IPv6Address` | ::1 | IPv6-адрес привязки. |
| `Password` | default_password | Пароль доступа к серверу. |
| `UseAuth` | true | Включает или отключает парольную аутентификацию. |
| `UseAuthIdentity` | true | Требует проверку DID-идентичности, когда auth включён. |
| `BasisUserRestrictionMode` | Normal | Режим ограничения входа: Normal, BlackList или WhiteList. |
| `HowManyDuplicateAuthCanExist` | 2 | Число одновременных подключений для одной auth-идентичности. |
| `AuthValidationTimeOutMiliseconds` | 9000 | Timeout auth-проверки, в миллисекундах. |
| `EnableConsole` | true | Включает интерактивную консоль сервера. |
| `DisableWriteUnlessAdminPersistentFlag` | true | Отклоняет постоянные key/value записи, если вызывающий не admin. |
| `DisableReadUnlessAdminPersistentFlag` | false | Отклоняет постоянные key/value чтения, если вызывающий не admin. |
| `UseNetworkFinalCompression` | false | Включает финальный проход сетевого сжатия. |
| `EnableBSRProfiling` | false | Выводит profiling Server Reduction System. |
| `DisallowHeadless` | false | Отклоняет headless-клиентов при подключении. |
| `AvatarsLocked` | false | Блокирует загрузку avatar для пользователей без bypass-права. |
| `PropsLocked` | false | Блокирует загрузку props для пользователей без bypass-права. |
| `WorldsLocked` | true | Блокирует загрузку worlds для пользователей без bypass-права. |

<small>Любая переменная окружения, имя которой совпадает с публичным полем конфигурации, переопределяет это поле при запуске.</small>

### Настройки аутентификации

```xml
<UseAuth>true</UseAuth>
```

```xml
<UseAuthIdentity>true</UseAuthIdentity>
```

```xml
<BasisUserRestrictionMode>Normal</BasisUserRestrictionMode>
```

```xml
<HowManyDuplicateAuthCanExist>2</HowManyDuplicateAuthCanExist>
```

## Загружаемые конфигурационные файлы

Можно настроить файлы мира и объектов для загрузки по запросу.
Они размещаются в папке `InitialResources`.

<Callout type="warn">
Используемые удалённые URL должны обслуживаться сервером с поддержкой чанкинга.
</Callout>

<Callout type="info" title="Для загрузки чего-либо">
Создайте сцену в Unity, экспортируйте как BEE-файл, загрузите на HTTP-сервер, затем поместите URL в `CombinedURL` и пароль в `UnlockPassword`.
</Callout>

| Переменная       | Определение |
|------------------|------------|
| `Mode`           | Режим конфигурации: `0` = Игровой объект, `1` = Сцена. |
| `LoadedNetID`    | Сетевой ID для ссылки. |
| `UnlockPassword` | Пароль для доступа к ресурсу. |
| `CombinedURL`    | URL к файлу `.BEE` |
| `IsLocalLoad`    | Указывает, загружается ли ресурс локально или из интернета. |
| `Persist`        | Продолжает ли объект существовать, если покинувший сервер игрок, создавший его, выходит? |
