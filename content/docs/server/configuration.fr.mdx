## Introduction

L'objectif ici est la configuration spécifique au serveur Basis, et non les nombreuses façons d'héberger des serveurs de jeux dans le cloud.

Le multithreading du serveur fonctionne mieux avec plus de cœurs disponibles, mais il a été démontré qu'il fonctionne bien avec aussi peu que deux cœurs. La VR sociale demande beaucoup de bande passante.

Ce document s'applique à un serveur Basis non modifié : Version 29 de la branche LTS, avril 2026

:::tip Conseil sur la version du serveur

BasisNetworkCore\BasisNetworkVersion.cs

### Compiler et exécuter sur Linux

#### Prérequis pour Debian/Ubuntu

Pour Ubuntu 22.04 :
`sudo add-apt-repository ppa:dotnet/backports`

Pour Debian ou configurations particulières :

```
wget https://packages.microsoft.com/config/debian/12/packages-microsoft-prod.deb -O packages-microsoft-prod.deb
sudo dpkg -i packages-microsoft-prod.deb
rm packages-microsoft-prod.deb
```

Puis poursuivez l'installation :

`sudo apt-get update && sudo apt-get install -y dotnet-sdk-10.0`

#### Obtenir Basis

Accédez au dossier souhaité et exécutez :

`git clone -b long-term-support-20260425 https://github.com/BasisVR/Basis`

#### Compiler le serveur Basis

Ouvrez un terminal et accédez au répertoire Basis Server : `cd Basis/Basis\ Server`

`dotnet restore`

Puis compilez :

`dotnet build` (pour le débogage)

ou

`dotnet build --configuration Release` (pour la release)

#### Exécuter

Accédez au répertoire BasisServerConsole et exécutez :

`dotnet .\BasisNetworkConsole.dll`

:::tip Pour une version Linux plus ciblée

`dotnet publish -f net10.0 --self-contained --os Linux`

Depuis `BasisServerConsole/bin/Debug/net10.0/BasisNetworkConsole`, exécutez `./BasisNetworkConsole`.

:::

## Fichiers de configuration

La première fois que vous exécutez le serveur, une variété de fichiers de configuration et de structures seront créés dans le répertoire où se trouve l'exe du serveur.

| Fichier/Dossier          | Description                                 |
|--------------------------|---------------------------------------------|
| `config.xml`             | Fichier de configuration principal du serveur. |
| `initialresources/`      | Ce répertoire contient les fichiers de monde et d'objet que le serveur chargera à la demande. |
| `Log/`                   | Dossier où les journaux du serveur sont stockés. |
| `admins.xml`             | Liste des utilisateurs avec des privilèges admin. |
| `banned_players.xml`     | Liste des comptes de joueurs bannis. |

## Config.xml

| Variable | Défaut | Description |
|---|---|---|
| `PeerLimit` | 65535 | Nombre maximal de pairs connectés. |
| `SetPort` | 4296 | Port UDP sur lequel le serveur écoute. |
| `UseNativeSockets` | true | Utilise les appels de socket natifs du système au lieu du chemin managé. |
| `NatPunchEnabled` | false | Active le NAT punch-through pour la mise en relation des pairs. |
| `PingInterval` | 1500 | Intervalle entre les pings de maintien, en millisecondes. |
| `DisconnectTimeout` | 30000 | Temps sans réponse avant de déconnecter un pair, en millisecondes. |
| `SimulatePacketLoss` | false | Supprime artificiellement des paquets sortants pour les tests. |
| `SimulateLatency` | false | Retarde artificiellement les paquets pour les tests. |
| `SimulationPacketLossChance` | 10 | Pourcentage de perte de paquets quand la simulation est activée. |
| `SimulationMinLatency` | 50 | Latence ajoutée minimale, en millisecondes. |
| `SimulationMaxLatency` | 150 | Latence ajoutée maximale, en millisecondes. |
| `ReconnectDelay` | 500 | Temps avant une tentative de reconnexion. |
| `MaxConnectAttempts` | 10 | Nombre maximal de tentatives de connexion. |
| `ReuseAddresss` | false | Option de réutilisation de socket ; notez l’orthographe du champ. |
| `DontRoute` | false | Option de routage du socket. |
| `EnableStatistics` | true | Collecte les statistiques de transport pour les rapports de santé et d’état. |
| `IPv6Enabled` | true | Active la prise en charge des sockets IPv6 dual-stack. |
| `MtuOverride` | 0 | Force une MTU fixe ; 0 désactive le remplacement. |
| `MtuDiscovery` | true | Active la découverte Path-MTU. |
| `DisconnectOnUnreachable` | false | Déconnecte lors d’un ICMP unreachable. |
| `AllowPeerAddressChange` | true | Autorise le changement d’endpoint d’un pair pendant la session. |
| `HasFileSupport` | true | Active l’écriture des logs, listes de modération, données d’identité auth et autres données sur disque. |
| `HealthCheckHost` | localhost | Hôte ou interface pour les health checks. Utilisez * pour lier toutes les interfaces. |
| `HealthCheckPort` | 10666 | Port TCP des health checks. |
| `HealthPath` | /health | Chemin de l’endpoint de health check. |
| `BSRSMillisecondDefaultInterval` | 50 | Intervalle d’envoi de base du Server Reduction System, en millisecondes. |
| `BSRBaseMultiplier` | 1 | Multiplicateur de base appliqué avant l’échelle par distance. |
| `BSRSIncreaseRate` | 0.005 | Vitesse à laquelle les intervalles d’envoi augmentent avec la distance. |
| `BSRSlowestSendRate` | 2.55 | Fréquence d’envoi la plus lente fournie aux clients pour les pairs éloignés. |
| `HighQualityDistance` | 3 | Seuil de distance pour la synchronisation avatar en haute qualité. |
| `MediumQualityDistance` | 10 | Seuil de distance pour la synchronisation avatar en qualité moyenne. |
| `LowQualityDistance` | 20 | Seuil de distance pour la synchronisation avatar en basse qualité. |
| `OverrideAutoDiscoveryOfIpv` | false | Lie exactement les adresses configurées au lieu de détecter automatiquement la version IP. |
| `IPv4Address` | 0.0.0.0 | Adresse de liaison IPv4. |
| `IPv6Address` | ::1 | Adresse de liaison IPv6. |
| `Password` | default_password | Mot de passe d’accès au serveur. |
| `UseAuth` | true | Active ou désactive l’authentification par mot de passe. |
| `UseAuthIdentity` | true | Exige la vérification d’identité DID quand l’authentification est active. |
| `BasisUserRestrictionMode` | Normal | Mode de restriction d’accès : Normal, BlackList ou WhiteList. |
| `HowManyDuplicateAuthCanExist` | 2 | Nombre de connexions simultanées autorisées pour la même identité auth. |
| `AuthValidationTimeOutMiliseconds` | 9000 | Timeout de validation auth, en millisecondes. |
| `EnableConsole` | true | Active la console interactive du serveur. |
| `DisableWriteUnlessAdminPersistentFlag` | true | Refuse les écritures key/value persistantes si l’appelant n’est pas admin. |
| `DisableReadUnlessAdminPersistentFlag` | false | Refuse les lectures key/value persistantes si l’appelant n’est pas admin. |
| `UseNetworkFinalCompression` | false | Active la passe finale de compression réseau. |
| `EnableBSRProfiling` | false | Émet la sortie de profiling du Server Reduction System. |
| `DisallowHeadless` | false | Refuse les clients headless à la connexion. |
| `AvatarsLocked` | false | Bloque le chargement d’avatars pour les utilisateurs sans permission bypass. |
| `PropsLocked` | false | Bloque le chargement de props pour les utilisateurs sans permission bypass. |
| `WorldsLocked` | true | Bloque le chargement de mondes pour les utilisateurs sans permission bypass. |

<small>Toute variable d'environnement dont le nom correspond à un champ de configuration public remplace ce champ au démarrage.</small>

### Paramètres d’authentification

```xml
<UseAuth>true</UseAuth>
```

```xml
<UseAuthIdentity>true</UseAuthIdentity>
```

```xml
<BasisUserRestrictionMode>Normal</BasisUserRestrictionMode>
```

```xml
<HowManyDuplicateAuthCanExist>2</HowManyDuplicateAuthCanExist>
```

## Fichiers de configuration chargeables

Vous pouvez configurer des fichiers de monde et d'objet à charger à la demande.
Ces fichiers sont placés dans le dossier `InitialResources`.

<Callout type="warn">
Les URLs distantes utilisées doivent être servies depuis un serveur approprié qui supporte le chunking.
Tout serveur moderne devrait le faire, mais les serveurs de développement locaux simples peuvent ne pas le faire.
</Callout>

<Callout type="info" title="Pour télécharger quelque chose">
Vous pouvez créer une scène dans Unity, l'exporter en tant que fichier BEE, la télécharger sur un serveur HTTP, puis placer l'URL dans `CombinedURL` et le mot de passe dans `UnlockPassword`.
</Callout>

| Variable         | Définition |
|------------------|------------|
| `Mode`           | Mode de la configuration : `0` = Objet de jeu, `1` = Scène. |
| `LoadedNetID`    | Un ID réseau de référence. |
| `UnlockPassword` | Mot de passe requis pour accéder à la ressource. |
| `CombinedURL`    | URL vers le fichier `.BEE` |
| `IsLocalLoad`    | Indique si la ressource est chargée localement ou depuis Internet. |
| `Persist`        | L'objet continue-t-il d'exister si le joueur qui l'a créé quitte le serveur ? |
