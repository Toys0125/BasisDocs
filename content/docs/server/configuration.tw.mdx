### 在 Linux 上編譯和執行

#### Debian/Ubuntu 的先決條件

對於 Ubuntu 22.04：
`sudo add-apt-repository ppa:dotnet/backports`

對於 Debian 或其他特殊設定：

```
wget https://packages.microsoft.com/config/debian/12/packages-microsoft-prod.deb -O packages-microsoft-prod.deb
sudo dpkg -i packages-microsoft-prod.deb
rm packages-microsoft-prod.deb
```

然後繼續安裝：

`sudo apt-get update && sudo apt-get install -y dotnet-sdk-10.0`

#### 取得 Basis

切換到所需資料夾並執行：

`git clone -b long-term-support-20260425 https://github.com/BasisVR/Basis`

#### 建置 Basis 伺服器

開啟終端並進入目錄：`cd Basis/Basis\ Server`

`dotnet restore`

然後建置：

`dotnet build`（用於除錯）

或

`dotnet build --configuration Release`（用於發布）

#### 執行

導覽至 BasisServerConsole 目錄並執行：

`dotnet .\BasisNetworkConsole.dll`

:::tip 用於更精確的 Linux 發布版本

`dotnet publish -f net10.0 --self-contained --os Linux`

從 `BasisServerConsole/bin/Debug/net10.0/BasisNetworkConsole` 執行 `./BasisNetworkConsole`。

:::

## 設定檔案

第一次執行伺服器時，會在伺服器 exe 所在目錄中建立各種設定檔案和結構。

| 檔案/資料夾              | 描述                                        |
|--------------------------|---------------------------------------------|
| `config.xml`             | 伺服器的主設定檔案。                        |
| `initialresources/`      | 包含伺服器將按需求載入的世界和物件檔案。    |
| `Log/`                   | 儲存伺服器日誌的資料夾。                    |
| `admins.xml`             | 具有管理員權限的使用者列表。                |
| `banned_players.xml`     | 被封禁的玩家帳戶列表。                      |

## Config.xml

| 變數 | 預設值 | 描述 |
|---|---|---|
| `PeerLimit` | 65535 | 已連線 peer 的最大数量。 |
| `SetPort` | 4296 | 伺服器监听的 UDP 連接埠。 |
| `UseNativeSockets` | true | 使用操作系统原生 socket 调用，而不是托管路径。 |
| `NatPunchEnabled` | false | 啟用用于 peer 引介的 NAT punch-through。 |
| `PingInterval` | 1500 | keep-alive ping 间隔，单位为毫秒。 |
| `DisconnectTimeout` | 30000 | peer 无响应多久后断开連線，单位为毫秒。 |
| `SimulatePacketLoss` | false | 为测试人为丢弃传出資料包。 |
| `SimulateLatency` | false | 为测试人为延迟資料包。 |
| `SimulationPacketLossChance` | 10 | 啟用丢包模拟时的丢包百分比。 |
| `SimulationMinLatency` | 50 | 最小附加延迟，单位为毫秒。 |
| `SimulationMaxLatency` | 150 | 最大附加延迟，单位为毫秒。 |
| `ReconnectDelay` | 500 | 尝试重新連線前的等待时间。 |
| `MaxConnectAttempts` | 10 | 最大連線尝试次数。 |
| `ReuseAddresss` | false | socket 地址复用选项；注意字段拼写。 |
| `DontRoute` | false | socket 路由选项。 |
| `EnableStatistics` | true | 收集传输统计資訊，用于健康和状态报告。 |
| `IPv6Enabled` | true | 啟用 IPv6 dual-stack socket 支持。 |
| `MtuOverride` | 0 | 强制固定 MTU；0 表示停用覆盖。 |
| `MtuDiscovery` | true | 啟用 Path-MTU 发现。 |
| `DisconnectOnUnreachable` | false | 收到 ICMP unreachable 时断开連線。 |
| `AllowPeerAddressChange` | true | 允许 peer endpoint 在会话期间变化。 |
| `HasFileSupport` | true | 啟用日志、审核列表、auth 身份資料和其他磁盘資料写入。 |
| `HealthCheckHost` | localhost | health check 使用的主机或接口。使用 * 綁定所有接口。 |
| `HealthCheckPort` | 10666 | health check 使用的 TCP 連接埠。 |
| `HealthPath` | /health | health check endpoint 路径。 |
| `BSRSMillisecondDefaultInterval` | 50 | Server Reduction System 的基础发送间隔，单位为毫秒。 |
| `BSRBaseMultiplier` | 1 | 距离缩放前应用的基础倍数。 |
| `BSRSIncreaseRate` | 0.005 | 发送间隔随距离增长的速度。 |
| `BSRSlowestSendRate` | 2.55 | 为远距离 peer 提供给客户端的最慢发送速率。 |
| `HighQualityDistance` | 3 | 高品質 avatar 同步的距离閾值。 |
| `MediumQualityDistance` | 10 | 中品質 avatar 同步的距离閾值。 |
| `LowQualityDistance` | 20 | 低品質 avatar 同步的距离閾值。 |
| `OverrideAutoDiscoveryOfIpv` | false | 綁定精确配置的地址，而不是自动检测 IP 版本。 |
| `IPv4Address` | 0.0.0.0 | IPv4 綁定地址。 |
| `IPv6Address` | ::1 | IPv6 綁定地址。 |
| `Password` | default_password | 伺服器存取密码。 |
| `UseAuth` | true | 啟用或停用密码认证。 |
| `UseAuthIdentity` | true | 啟用 auth 时要求 DID 身份驗證。 |
| `BasisUserRestrictionMode` | Normal | 加入限制模式：Normal、BlackList 或 WhiteList。 |
| `HowManyDuplicateAuthCanExist` | 2 | 同一 auth 身份允许的同时連線数。 |
| `AuthValidationTimeOutMiliseconds` | 9000 | auth 驗證超时，单位为毫秒。 |
| `EnableConsole` | true | 啟用交互式伺服器控制台。 |
| `DisableWriteUnlessAdminPersistentFlag` | true | 如果呼叫者不是 admin，则拒绝持久 key/value 写入。 |
| `DisableReadUnlessAdminPersistentFlag` | false | 如果呼叫者不是 admin，则拒绝持久 key/value 读取。 |
| `UseNetworkFinalCompression` | false | 啟用最终网络压缩步骤。 |
| `EnableBSRProfiling` | false | 输出 Server Reduction System profiling 資訊。 |
| `DisallowHeadless` | false | 連線时拒绝 headless 客户端。 |
| `AvatarsLocked` | false | 阻止没有 bypass 权限的使用者載入 avatar。 |
| `PropsLocked` | false | 阻止没有 bypass 权限的使用者載入 prop。 |
| `WorldsLocked` | true | 阻止没有 bypass 权限的使用者載入 world。 |

<small>任何名稱與公開設定欄位相符的環境變數，都會在啟動時覆寫該欄位。</small>

### 身分驗證設定

```xml
<UseAuth>true</UseAuth>
```



## 可載入設定檔案

您可以設定世界和物件檔案以按需載入。
這些檔案放置在 `InitialResources` 資料夾中。

<Callout type="warn">
使用的遠端 URL 必須從支援分塊的適當伺服器提供。
</Callout>

<Callout type="info" title="上傳內容">
在 Unity 中建立場景，將其匯出為 BEE 檔案，上傳到 HTTP 伺服器，然後將 URL 放入 `CombinedURL`，將密碼放入 `UnlockPassword`。
</Callout>

| 變數             | 定義 |
|------------------|------------|
| `Mode`           | 設定模式：`0` = 遊戲物件，`1` = 場景。 |
| `LoadedNetID`    | 作為參照的網路 ID。 |
| `UnlockPassword` | 存取資源所需的密碼。 |
| `CombinedURL`    | 指向 `.BEE` 檔案的 URL |
| `IsLocalLoad`    | 指示資源是從本地載入還是從網際網路載入。 |
| `Persist`        | 如果生成該物件的玩家離開伺服器，物件是否繼續存在？ |
