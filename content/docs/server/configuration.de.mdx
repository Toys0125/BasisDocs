### Kompilieren und unter Linux ausführen

#### Voraussetzungen für Debian/Ubuntu

Für Ubuntu 22.04:
`sudo add-apt-repository ppa:dotnet/backports`

Für Debian oder andere Setups:

```
wget https://packages.microsoft.com/config/debian/12/packages-microsoft-prod.deb -O packages-microsoft-prod.deb
sudo dpkg -i packages-microsoft-prod.deb
rm packages-microsoft-prod.deb
```

Dann Installation fortsetzen:

`sudo apt-get update && sudo apt-get install -y dotnet-sdk-10.0`

#### Basis herunterladen

Wechseln Sie in den gewünschten Ordner und führen Sie aus:

`git clone -b long-term-support-20260425 https://github.com/BasisVR/Basis`

#### Basis Server kompilieren

Öffnen Sie ein Terminal und wechseln Sie ins Verzeichnis: `cd Basis/Basis\ Server`

`dotnet restore`

Dann kompilieren:

`dotnet build` (für Debug)

oder

`dotnet build --configuration Release` (für Release)

#### Ausführen

Navigieren Sie zum BasisServerConsole-Verzeichnis und führen Sie aus:

`dotnet .\BasisNetworkConsole.dll`

:::tip Für ein gezieltes Linux-Release

`dotnet publish -f net10.0 --self-contained --os Linux`

Aus `BasisServerConsole/bin/Debug/net10.0/BasisNetworkConsole` führen Sie `./BasisNetworkConsole` aus.

:::

## Konfigurationsdateien

Beim ersten Ausführen des Servers werden verschiedene Konfigurationsdateien und Strukturen im Verzeichnis der Server-Exe erstellt.

| Datei/Ordner             | Beschreibung                                |
|--------------------------|---------------------------------------------|
| `config.xml`             | Hauptkonfigurationsdatei des Servers.       |
| `initialresources/`      | Enthält Welt- und Objektdateien, die der Server auf Anfrage lädt. |
| `Log/`                   | Ordner für Server-Logs.                     |
| `admins.xml`             | Liste der Benutzer mit Admin-Rechten.       |
| `banned_players.xml`     | Liste der gesperrten Spielerkonten.         |

## Config.xml

| Variable | Standard | Beschreibung |
|---|---|---|
| `PeerLimit` | 65535 | Maximale Anzahl verbundener Peers. |
| `SetPort` | 4296 | UDP-Port, auf dem der Server lauscht. |
| `UseNativeSockets` | true | Verwendet native Socket-Aufrufe des Betriebssystems statt des verwalteten Pfads. |
| `NatPunchEnabled` | false | Aktiviert NAT-Punch-through für Peer-Einführungen. |
| `PingInterval` | 1500 | Intervall zwischen Keep-alive-Pings in Millisekunden. |
| `DisconnectTimeout` | 30000 | Zeit ohne Antwort, bevor ein Peer getrennt wird, in Millisekunden. |
| `SimulatePacketLoss` | false | Lässt ausgehende Pakete künstlich fallen, nur für Tests. |
| `SimulateLatency` | false | Verzögert Pakete künstlich, nur für Tests. |
| `SimulationPacketLossChance` | 10 | Paketverlust-Prozentsatz, wenn Paketverlustsimulation aktiviert ist. |
| `SimulationMinLatency` | 50 | Minimale zusätzliche Latenz in Millisekunden. |
| `SimulationMaxLatency` | 150 | Maximale zusätzliche Latenz in Millisekunden. |
| `ReconnectDelay` | 500 | Zeit vor einem Wiederverbindungsversuch. |
| `MaxConnectAttempts` | 10 | Maximale Anzahl von Verbindungsversuchen. |
| `ReuseAddresss` | false | Socket-Reuse-Option; beachten Sie die Schreibweise des Feldnamens. |
| `DontRoute` | false | Socket-Routing-Option. |
| `EnableStatistics` | true | Sammelt Transportstatistiken für Health- und Statusberichte. |
| `IPv6Enabled` | true | Aktiviert IPv6-Dual-Stack-Socket-Unterstützung. |
| `MtuOverride` | 0 | Erzwingt eine feste MTU; 0 deaktiviert die Überschreibung. |
| `MtuDiscovery` | true | Aktiviert Path-MTU-Erkennung. |
| `DisconnectOnUnreachable` | false | Trennt bei ICMP-Unreachable. |
| `AllowPeerAddressChange` | true | Erlaubt, dass sich der Endpunkt eines Peers während der Sitzung ändert. |
| `HasFileSupport` | true | Aktiviert das Schreiben von Logs, Moderationslisten, Auth-Identitätsdaten und anderen dateibasierten Daten. |
| `HealthCheckHost` | localhost | Host oder Interface für Health Checks. Mit * an alle Interfaces binden. |
| `HealthCheckPort` | 10666 | TCP-Port für Health Checks. |
| `HealthPath` | /health | Pfad zum Health-Check-Endpunkt. |
| `BSRSMillisecondDefaultInterval` | 50 | Basis-Sendeintervall des Server Reduction Systems in Millisekunden. |
| `BSRBaseMultiplier` | 1 | Basismultiplikator vor der Distanzskalierung. |
| `BSRSIncreaseRate` | 0.005 | Wie schnell Sendeintervalle mit der Entfernung wachsen. |
| `BSRSlowestSendRate` | 2.55 | Langsamste Senderate, die Clients für entfernte Peers erhalten. |
| `HighQualityDistance` | 3 | Distanzschwelle für Avatar-Sync in hoher Qualität. |
| `MediumQualityDistance` | 10 | Distanzschwelle für Avatar-Sync in mittlerer Qualität. |
| `LowQualityDistance` | 20 | Distanzschwelle für Avatar-Sync in niedriger Qualität. |
| `OverrideAutoDiscoveryOfIpv` | false | Bindet exakt die konfigurierten Adressen statt die IP-Version automatisch zu erkennen. |
| `IPv4Address` | 0.0.0.0 | IPv4-Bind-Adresse. |
| `IPv6Address` | ::1 | IPv6-Bind-Adresse. |
| `Password` | default_password | Server-Zugangspasswort. |
| `UseAuth` | true | Aktiviert oder deaktiviert Passwortauthentifizierung. |
| `UseAuthIdentity` | true | Erfordert DID-Identitätsprüfung, wenn Authentifizierung aktiviert ist. |
| `BasisUserRestrictionMode` | Normal | Beitrittsbeschränkung: Normal, BlackList oder WhiteList. |
| `HowManyDuplicateAuthCanExist` | 2 | Anzahl gleichzeitiger Verbindungen mit derselben Auth-Identität. |
| `AuthValidationTimeOutMiliseconds` | 9000 | Timeout für Auth-Validierung in Millisekunden. |
| `EnableConsole` | true | Aktiviert die interaktive Serverkonsole. |
| `DisableWriteUnlessAdminPersistentFlag` | true | Lehnt persistente Key/Value-Schreibzugriffe ab, wenn der Aufrufer kein Admin ist. |
| `DisableReadUnlessAdminPersistentFlag` | false | Lehnt persistente Key/Value-Lesezugriffe ab, wenn der Aufrufer kein Admin ist. |
| `UseNetworkFinalCompression` | false | Aktiviert den finalen Netzwerk-Kompressionsschritt. |
| `EnableBSRProfiling` | false | Gibt Profiling-Ausgaben des Server Reduction Systems aus. |
| `DisallowHeadless` | false | Weist Headless-Clients beim Verbinden ab. |
| `AvatarsLocked` | false | Blockiert Avatar-Laden für Benutzer ohne Bypass-Berechtigung. |
| `PropsLocked` | false | Blockiert Prop-Laden für Benutzer ohne Bypass-Berechtigung. |
| `WorldsLocked` | true | Blockiert Welt-Laden für Benutzer ohne Bypass-Berechtigung. |

<small>Jede Umgebungsvariable, deren Name einem öffentlichen Konfigurationsfeld entspricht, überschreibt dieses Feld beim Start.</small>

## Ladbare Konfigurationsdateien

Sie können Welt- und Objektdateien für das Laden auf Anfrage konfigurieren.
Diese Dateien werden im Ordner `InitialResources` abgelegt.

<Callout type="warn">
Die verwendeten Remote-URLs müssen von einem Server bereitgestellt werden, der Chunking unterstützt.
</Callout>

<Callout type="info" title="Um etwas hochzuladen">
Erstellen Sie eine Szene in Unity, exportieren Sie sie als BEE-Datei, laden Sie sie auf einen HTTP-Server hoch, dann setzen Sie die URL in `CombinedURL` und das Passwort in `UnlockPassword`.
</Callout>

| Variable         | Definition |
|------------------|------------|
| `Mode`           | Modus der Konfiguration: `0` = Spielobjekt, `1` = Szene. |
| `LoadedNetID`    | Eine Netzwerk-ID als Referenz. |
| `UnlockPassword` | Passwort für den Zugriff auf die Ressource. |
| `CombinedURL`    | URL zur `.BEE`-Datei |
| `IsLocalLoad`    | Gibt an, ob die Ressource lokal oder aus dem Internet geladen wird. |
| `Persist`        | Besteht das Objekt weiter, wenn der Spieler, der es gespawnt hat, den Server verlässt? |
