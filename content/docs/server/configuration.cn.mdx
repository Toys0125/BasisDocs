### 在 Linux 上编译和运行

#### Debian/Ubuntu 的先决条件

对于 Ubuntu 22.04：
`sudo add-apt-repository ppa:dotnet/backports`

对于 Debian 或其他特殊设置：

```
wget https://packages.microsoft.com/config/debian/12/packages-microsoft-prod.deb -O packages-microsoft-prod.deb
sudo dpkg -i packages-microsoft-prod.deb
rm packages-microsoft-prod.deb
```

然后继续安装：

`sudo apt-get update && sudo apt-get install -y dotnet-sdk-10.0`

#### 获取 Basis

切换到所需文件夹并执行：

`git clone -b long-term-support-20260425 https://github.com/BasisVR/Basis`

#### 构建 Basis 服务器

打开终端并进入目录：`cd Basis/Basis\ Server`

`dotnet restore`

然后构建：

`dotnet build`（用于调试）

或

`dotnet build --configuration Release`（用于发布）

#### 执行

导航到 BasisServerConsole 目录并运行：

`dotnet .\BasisNetworkConsole.dll`

:::tip 用于更精确的 Linux 发布版本

`dotnet publish -f net10.0 --self-contained --os Linux`

从 `BasisServerConsole/bin/Debug/net10.0/BasisNetworkConsole` 运行 `./BasisNetworkConsole`。

:::

## 配置文件

第一次运行服务器时，会在服务器 exe 所在目录中创建各种配置文件和结构。

| 文件/文件夹              | 描述                                        |
|--------------------------|---------------------------------------------|
| `config.xml`             | 服务器的主配置文件。                        |
| `initialresources/`      | 包含服务器将按请求加载的世界和对象文件。    |
| `Log/`                   | 存储服务器日志的文件夹。                    |
| `admins.xml`             | 具有管理员权限的用户列表。                  |
| `banned_players.xml`     | 被封禁的玩家账户列表。                      |

## Config.xml

| 变量 | 默认值 | 描述 |
|---|---|---|
| `PeerLimit` | 65535 | 已连接 peer 的最大数量。 |
| `SetPort` | 4296 | 服务器监听的 UDP 端口。 |
| `UseNativeSockets` | true | 使用操作系统原生 socket 调用，而不是托管路径。 |
| `NatPunchEnabled` | false | 启用用于 peer 引介的 NAT punch-through。 |
| `PingInterval` | 1500 | keep-alive ping 间隔，单位为毫秒。 |
| `DisconnectTimeout` | 30000 | peer 无响应多久后断开连接，单位为毫秒。 |
| `SimulatePacketLoss` | false | 为测试人为丢弃传出数据包。 |
| `SimulateLatency` | false | 为测试人为延迟数据包。 |
| `SimulationPacketLossChance` | 10 | 启用丢包模拟时的丢包百分比。 |
| `SimulationMinLatency` | 50 | 最小附加延迟，单位为毫秒。 |
| `SimulationMaxLatency` | 150 | 最大附加延迟，单位为毫秒。 |
| `ReconnectDelay` | 500 | 尝试重新连接前的等待时间。 |
| `MaxConnectAttempts` | 10 | 最大连接尝试次数。 |
| `ReuseAddresss` | false | socket 地址复用选项；注意字段拼写。 |
| `DontRoute` | false | socket 路由选项。 |
| `EnableStatistics` | true | 收集传输统计信息，用于健康和状态报告。 |
| `IPv6Enabled` | true | 启用 IPv6 dual-stack socket 支持。 |
| `MtuOverride` | 0 | 强制固定 MTU；0 表示禁用覆盖。 |
| `MtuDiscovery` | true | 启用 Path-MTU 发现。 |
| `DisconnectOnUnreachable` | false | 收到 ICMP unreachable 时断开连接。 |
| `AllowPeerAddressChange` | true | 允许 peer endpoint 在会话期间变化。 |
| `HasFileSupport` | true | 启用日志、审核列表、auth 身份数据和其他磁盘数据写入。 |
| `HealthCheckHost` | localhost | health check 使用的主机或接口。使用 * 绑定所有接口。 |
| `HealthCheckPort` | 10666 | health check 使用的 TCP 端口。 |
| `HealthPath` | /health | health check endpoint 路径。 |
| `BSRSMillisecondDefaultInterval` | 50 | Server Reduction System 的基础发送间隔，单位为毫秒。 |
| `BSRBaseMultiplier` | 1 | 距离缩放前应用的基础倍数。 |
| `BSRSIncreaseRate` | 0.005 | 发送间隔随距离增长的速度。 |
| `BSRSlowestSendRate` | 2.55 | 为远距离 peer 提供给客户端的最慢发送速率。 |
| `HighQualityDistance` | 3 | 高质量 avatar 同步的距离阈值。 |
| `MediumQualityDistance` | 10 | 中质量 avatar 同步的距离阈值。 |
| `LowQualityDistance` | 20 | 低质量 avatar 同步的距离阈值。 |
| `OverrideAutoDiscoveryOfIpv` | false | 绑定精确配置的地址，而不是自动检测 IP 版本。 |
| `IPv4Address` | 0.0.0.0 | IPv4 绑定地址。 |
| `IPv6Address` | ::1 | IPv6 绑定地址。默认值 `::1` 仅绑定本机；如需和 `IPv4Address` 的 `0.0.0.0` 一样监听所有 IPv6 接口，请改为 `::`。 |
| `Password` | default_password | 服务器访问密码。 |
| `UseAuth` | true | 启用或禁用密码认证。 |
| `UseAuthIdentity` | true | 启用 auth 时要求 DID 身份验证。 |
| `BasisUserRestrictionMode` | Normal | 加入限制模式：Normal、BlackList 或 WhiteList。 |
| `HowManyDuplicateAuthCanExist` | 2 | 同一 auth 身份允许的同时连接数。 |
| `AuthValidationTimeOutMiliseconds` | 9000 | auth 验证超时，单位为毫秒。 |
| `EnableConsole` | true | 启用交互式服务器控制台。 |
| `DisableWriteUnlessAdminPersistentFlag` | true | 如果调用者不是 admin，则拒绝持久 key/value 写入。 |
| `DisableReadUnlessAdminPersistentFlag` | false | 如果调用者不是 admin，则拒绝持久 key/value 读取。 |
| `UseNetworkFinalCompression` | false | 启用最终网络压缩步骤。 |
| `EnableBSRProfiling` | false | 输出 Server Reduction System profiling 信息。 |
| `DisallowHeadless` | false | 连接时拒绝 headless 客户端。 |
| `AvatarsLocked` | false | 阻止没有 bypass 权限的用户加载 avatar。 |
| `PropsLocked` | false | 阻止没有 bypass 权限的用户加载 prop。 |
| `WorldsLocked` | true | 阻止没有 bypass 权限的用户加载 world。 |

<small>任何名称与公共配置字段匹配的环境变量将在启动时覆盖该字段。</small>

<Callout type="warn" title="更改默认密码">
`Password` 字段的默认值是 `default_password`。在生产环境中运行服务器前请务必更改该值，并使用强随机密码或生成的密钥。
</Callout>

### 身份验证设置

```xml
<UseAuth>true</UseAuth>
```

```xml

```

```xml

```

```xml

```

## 可加载配置文件

您可以设置世界和对象文件以按需加载。
这些文件放置在 `InitialResources` 文件夹中。

<Callout type="warn">
使用的远程 URL 必须从支持分块的适当服务器提供。
</Callout>

<Callout type="info" title="上传内容">
在 Unity 中创建场景，将其导出为 BEE 文件，上传到 HTTP 服务器，然后将 URL 放入 `CombinedURL`，将密码放入 `UnlockPassword`。
</Callout>

| 变量             | 定义 |
|------------------|------------|
| `Mode`           | 配置模式：`0` = 游戏对象，`1` = 场景。 |
| `LoadedNetID`    | 作为引用的网络 ID。 |
| `UnlockPassword` | 访问资源所需的密码。 |
| `CombinedURL`    | 指向 `.BEE` 文件的 URL |
| `IsLocalLoad`    | 指示资源是从本地加载还是从互联网加载。 |
| `Persist`        | 如果生成该对象的玩家离开服务器，对象是否继续存在？ |
