### Compilazione ed esecuzione su Linux

#### Requisiti per Debian/Ubuntu

Per Ubuntu 22.04,
`sudo add-apt-repository ppa:dotnet/backports`

Per Debian o altre configurazioni particolari:

```
wget https://packages.microsoft.com/config/debian/12/packages-microsoft-prod.deb -O packages-microsoft-prod.deb
sudo dpkg -i packages-microsoft-prod.deb
rm packages-microsoft-prod.deb
```

Poi continua con l'installazione:

`sudo apt-get update && sudo apt-get install -y dotnet-sdk-10.0`

#### Ottenere Basis

Vai alla directory in cui vuoi scaricare Basis ed esegui il seguente comando:

`git clone -b long-term-support-20260425 https://github.com/BasisVR/Basis`

#### Compilare il Basis Server

Apri un nuovo terminale e vai alla cartella contenente il Basis Server, ad es. `cd Basis/Basis\ Server`

`dotnet restore`

Poi compila con:

`dotnet build` (per debug)

oppure

`dotnet build --configuration Release` (per release)

#### Esecuzione

Vai alla cartella BasisServerConsole (qualcosa come `/BasisServerConsole/bin/Debug/net10.0/BasisNetworkConsole`)
ed esegui:

`dotnet .\BasisNetworkConsole.dll`

## Firewall

Potresti voler aprire le seguenti porte:
 * 1234/tcp
 * 10666/tcp
 * 4296/udp

## File di configurazione

La prima volta che esegui il server, vengono creati vari file di configurazione e una struttura nella cartella dove si trova l'exe del server.

| File/Cartella            | Descrizione                                 |
|--------------------------|---------------------------------------------|
| `config.xml`             | File di configurazione principale del server. |
| `initialresources/`      | Questa cartella contiene file di mondo e oggetti che il server carica su richiesta. |
| `Log/`                   | Cartella dove vengono salvati i log del server. |
| `admins.xml`             | Elenco degli utenti con privilegi di amministratore. |
| `banned_players.xml`     | Elenco degli account giocatori bannati. |

## Config.xml

| Variabile | Predefinito | Descrizione |
|---|---|---|
| `PeerLimit` | 65535 | Numero massimo di peer connessi. |
| `SetPort` | 4296 | Porta UDP su cui il server ascolta. |
| `UseNativeSockets` | true | Usa chiamate socket native del sistema operativo invece del percorso gestito. |
| `NatPunchEnabled` | false | Abilita NAT punch-through per introdurre peer. |
| `PingInterval` | 1500 | Intervallo tra ping keep-alive, in millisecondi. |
| `DisconnectTimeout` | 30000 | Tempo senza risposta prima di disconnettere un peer, in millisecondi. |
| `SimulatePacketLoss` | false | Scarta artificialmente pacchetti in uscita per test. |
| `SimulateLatency` | false | Ritarda artificialmente i pacchetti per test. |
| `SimulationPacketLossChance` | 10 | Percentuale di perdita pacchetti quando la simulazione è attiva. |
| `SimulationMinLatency` | 50 | Latenza aggiuntiva minima, in millisecondi. |
| `SimulationMaxLatency` | 150 | Latenza aggiuntiva massima, in millisecondi. |
| `ReconnectDelay` | 500 | Tempo prima di tentare la riconnessione. |
| `MaxConnectAttempts` | 10 | Numero massimo di tentativi di connessione. |
| `ReuseAddresss` | false | Opzione di riuso socket; nota l’ortografia del campo. |
| `DontRoute` | false | Opzione di routing del socket. |
| `EnableStatistics` | true | Raccoglie statistiche di trasporto per salute e stato. |
| `IPv6Enabled` | true | Abilita supporto socket IPv6 dual-stack. |
| `MtuOverride` | 0 | Forza una MTU fissa; 0 disabilita la sovrascrittura. |
| `MtuDiscovery` | true | Abilita discovery Path-MTU. |
| `DisconnectOnUnreachable` | false | Disconnette su ICMP unreachable. |
| `AllowPeerAddressChange` | true | Permette a un endpoint peer di cambiare durante la sessione. |
| `HasFileSupport` | true | Abilita scrittura di log, liste moderazione, dati identità auth e altri dati su disco. |
| `HealthCheckHost` | localhost | Host o interfaccia per health check. Usa * per tutte le interfacce. |
| `HealthCheckPort` | 10666 | Porta TCP per health check. |
| `HealthPath` | /health | Percorso endpoint health check. |
| `BSRSMillisecondDefaultInterval` | 50 | Intervallo base di invio del Server Reduction System, in millisecondi. |
| `BSRBaseMultiplier` | 1 | Moltiplicatore base prima della scala per distanza. |
| `BSRSIncreaseRate` | 0.005 | Quanto rapidamente gli intervalli di invio crescono con la distanza. |
| `BSRSlowestSendRate` | 2.55 | Frequenza di invio più lenta data ai client per peer distanti. |
| `HighQualityDistance` | 3 | Soglia distanza per sync avatar alta qualità. |
| `MediumQualityDistance` | 10 | Soglia distanza per sync avatar qualità media. |
| `LowQualityDistance` | 20 | Soglia distanza per sync avatar bassa qualità. |
| `OverrideAutoDiscoveryOfIpv` | false | Associa esattamente gli indirizzi configurati invece di rilevare automaticamente la versione IP. |
| `IPv4Address` | 0.0.0.0 | Indirizzo di bind IPv4. |
| `IPv6Address` | :: | Indirizzo di bind IPv6. |
| `Password` | default_password | Password di accesso al server. |
| `UseAuth` | true | Abilita o disabilita autenticazione password. |
| `UseAuthIdentity` | true | Richiede verifica identità DID quando auth è attivo. |
| `BasisUserRestrictionMode` | Normal | Modalità restrizione ingresso: Normal, BlackList o WhiteList. |
| `HowManyDuplicateAuthCanExist` | 2 | Numero di connessioni simultanee per la stessa identità auth. |
| `AuthValidationTimeOutMiliseconds` | 9000 | Timeout validazione auth, in millisecondi. |
| `EnableConsole` | true | Abilita console interattiva server. |
| `DisableWriteUnlessAdminPersistentFlag` | true | Rifiuta scritture key/value persistenti se il chiamante non è admin. |
| `DisableReadUnlessAdminPersistentFlag` | false | Rifiuta letture key/value persistenti se il chiamante non è admin. |
| `UseNetworkFinalCompression` | false | Abilita passaggio finale di compressione rete. |
| `EnableBSRProfiling` | false | Emette output profiling del Server Reduction System. |
| `DisallowHeadless` | false | Rifiuta client headless alla connessione. |
| `AvatarsLocked` | false | Blocca caricamento avatar per utenti senza permesso bypass. |
| `PropsLocked` | false | Blocca caricamento prop per utenti senza permesso bypass. |
| `WorldsLocked` | true | Blocca caricamento mondi per utenti senza permesso bypass. |

<small>Qualsiasi variabile d'ambiente il cui nome corrisponde a un campo di configurazione pubblico sovrascrive quel campo all'avvio.</small>

## File di configurazione caricabili

Puoi impostare file di mondo e oggetti da caricare su richiesta.
Questi sono i file che metti nella cartella `InitialResources`.

<Callout type="warn">
Tieni presente che gli URL esterni che utilizzi devono essere forniti da un server adeguato che supporti il chunking.
Qualsiasi server moderno dovrebbe farlo, ma i semplici server di sviluppo locali potrebbero non farlo.
</Callout>

<Callout type="info" title="Caricare qualcosa">
Un modo per testare una nuova scena è creare una scena in Unity, esportarla come file BEE. Carica quel file BEE su un server che supporta HTTP, poi inserisci l'URL in `CombinedURL` e recupera la password da `dontuploadmepassword.txt` e inseriscila in `UnlockPassword`.
</Callout>

| Variabile        | Definizione |
|------------------|------------|
| `Mode`           | Modalità della configurazione: `0` = GameObject, `1` = Scena. |
| `LoadedNetID`    | Un ID di rete: il server mantiene un elenco di oggetti di rete che i client possono interrogare e spawnare con questo valore come riferimento. |
| `UnlockPassword` | Password richiesta per sbloccare o accedere alla risorsa. |
| `CombinedURL`    | URL al file `.BEE` |
| `IsLocalLoad`    | Indica se la risorsa viene caricata localmente (`true`) o da internet (`false`). |
| `PositionX`      | Posizione mondiale sull'asse X dell'oggetto. |
| `PositionY`      | Posizione mondiale sull'asse Y dell'oggetto. |
| `PositionZ`      | Posizione mondiale sull'asse Z dell'oggetto. |
| `QuaternionX`    | Componente X della rotazione dell'oggetto (quaternione). |
| `QuaternionY`    | Componente Y della rotazione dell'oggetto (quaternione). |
| `QuaternionZ`    | Componente Z della rotazione dell'oggetto (quaternione). |
| `QuaternionW`    | Componente W della rotazione dell'oggetto (quaternione). |
| `ScaleX`         | Fattore di scala sull'asse X. |
| `ScaleY`         | Fattore di scala sull'asse Y. |
| `ScaleZ`         | Fattore di scala sull'asse Z. |
| `Persist`        | Se il giocatore che ha spawnato l'oggetto lascia il server, l'oggetto continua a esistere? |

### Configurazione di esempio

```xml title="BasisLoadableConfiguration-esempio"
<BasisLoadableConfiguration>

    <!-- Mode of the configuration: Mode  0 = Game object, 1 = Scene -->
    <Mode>0</Mode>

    <!-- A Network ID: Server keeps a list of Network Objects that Clients can query and spawn with this value. -->
    <LoadedNetID></LoadedNetID>

    <!-- Unlock password -->
    <UnlockPassword>ffee4439eff</UnlockPassword>

    <!-- Combined URL link to BEE file -->
    <CombinedURL>https://www.example.com/2lkj23j.BEE</CombinedURL>

    <!-- Does this resource exist on the internet or in the client? -->
    <IsLocalLoad>false</IsLocalLoad>

    <!-- Position values -->
    <PositionX>0</PositionX>
    <PositionY>0</PositionY>
    <PositionZ>0</PositionZ>

    <!-- Quaternion values -->
    <QuaternionX>0</QuaternionX>
    <QuaternionY>0</QuaternionY>
    <QuaternionZ>0</QuaternionZ>
    <QuaternionW>1</QuaternionW>

    <!-- Scale values -->
    <ScaleX>1</ScaleX>
    <ScaleY>1</ScaleY>
    <ScaleZ>1</ScaleZ>

    <!--  If the player that spawned the object leaves the server does the object continue to exist?  -->
    <Persist>false</Persist>

</BasisLoadableConfiguration>
```
