### Linuxでコンパイルして実行する

#### Debian/Ubuntuの前提条件

Ubuntu 22.04の場合：
`sudo add-apt-repository ppa:dotnet/backports`

Debianまたはその他のセットアップ：

```
wget https://packages.microsoft.com/config/debian/12/packages-microsoft-prod.deb -O packages-microsoft-prod.deb
sudo dpkg -i packages-microsoft-prod.deb
rm packages-microsoft-prod.deb
```

インストールを続けます：

`sudo apt-get update && sudo apt-get install -y dotnet-sdk-10.0`

#### Basisを取得する

希望するフォルダに移動して実行します：

`git clone -b long-term-support-20260425 https://github.com/BasisVR/Basis`

#### Basisサーバーをビルドする

端末を開いてディレクトリに移動します：`cd Basis/Basis\ Server`

`dotnet restore`

ビルドします：

`dotnet build`（デバッグ用）

または

`dotnet build --configuration Release`（リリース用）

#### 実行する

BasisServerConsoleディレクトリに移動して実行します：

`dotnet .\BasisNetworkConsole.dll`

:::tip より特定的なLinuxリリースの場合

`dotnet publish -f net10.0 --self-contained --os Linux`

`BasisServerConsole/bin/Debug/net10.0/BasisNetworkConsole`から`./BasisNetworkConsole`を実行してください。

:::

## ファイアウォール

以下のポートを開く必要があるかもしれません：
 * 1234/tcp
 * 10666/tcp
 * 4296/udp

## 設定ファイル

サーバーを初めて実行すると、サーバーexeが置かれているディレクトリにさまざまな設定ファイルと構造が作成されます。

| ファイル/フォルダ        | 説明                                        |
|--------------------------|---------------------------------------------|
| `config.xml`             | サーバーのメイン設定ファイル。              |
| `initialresources/`      | リクエストに応じてサーバーが読み込むワールドとオブジェクトファイル。 |
| `Log/`                   | サーバーログが保存されるフォルダ。          |
| `admins.xml`             | 管理者権限を持つユーザーのリスト。          |
| `banned_players.xml`     | BANされたプレイヤーアカウントのリスト。     |

## Config.xml

| 変数 | 既定値 | 説明 |
|---|---|---|
| `PeerLimit` | 65535 | 接続済み peer の最大数。 |
| `SetPort` | 4296 | サーバーが待ち受ける UDP ポート。 |
| `UseNativeSockets` | true | 管理パスではなく OS ネイティブの socket 呼び出しを使用します。 |
| `NatPunchEnabled` | false | peer の紹介に NAT punch-through を有効にします。 |
| `PingInterval` | 1500 | keep-alive ping の間隔（ミリ秒）。 |
| `DisconnectTimeout` | 30000 | 応答がない peer を切断するまでの時間（ミリ秒）。 |
| `SimulatePacketLoss` | false | テスト用に送信パケットを人工的に破棄します。 |
| `SimulateLatency` | false | テスト用にパケットを人工的に遅延させます。 |
| `SimulationPacketLossChance` | 10 | パケットロスシミュレーション有効時のロス率。 |
| `SimulationMinLatency` | 50 | 追加される最小遅延（ミリ秒）。 |
| `SimulationMaxLatency` | 150 | 追加される最大遅延（ミリ秒）。 |
| `ReconnectDelay` | 500 | 再接続を試みるまでの時間。 |
| `MaxConnectAttempts` | 10 | 最大接続試行回数。 |
| `ReuseAddresss` | false | socket 再利用オプション。フィールド名の綴りに注意してください。 |
| `DontRoute` | false | socket ルーティングオプション。 |
| `EnableStatistics` | true | health/status レポート用の転送統計を収集します。 |
| `IPv6Enabled` | true | IPv6 dual-stack socket サポートを有効にします。 |
| `MtuOverride` | 0 | 固定 MTU を強制します。0 は上書きを無効にします。 |
| `MtuDiscovery` | true | Path-MTU discovery を有効にします。 |
| `DisconnectOnUnreachable` | false | ICMP unreachable で切断します。 |
| `AllowPeerAddressChange` | true | セッション中に peer endpoint が変わることを許可します。 |
| `HasFileSupport` | true | ログ、モデレーションリスト、auth ID データなどのディスク書き込みを有効にします。 |
| `HealthCheckHost` | localhost | health check 用のホストまたはインターフェイス。* ですべてのインターフェイスにバインドします。 |
| `HealthCheckPort` | 10666 | health check 用 TCP ポート。 |
| `HealthPath` | /health | health check endpoint のパス。 |
| `BSRSMillisecondDefaultInterval` | 50 | Server Reduction System の基本送信間隔（ミリ秒）。 |
| `BSRBaseMultiplier` | 1 | 距離スケーリング前に適用される基本倍率。 |
| `BSRSIncreaseRate` | 0.005 | 距離に応じて送信間隔が増加する速さ。 |
| `BSRSlowestSendRate` | 2.55 | 遠距離 peer に対してクライアントへ渡す最も遅い送信レート。 |
| `HighQualityDistance` | 3 | 高品質 avatar 同期の距離しきい値。 |
| `MediumQualityDistance` | 10 | 中品質 avatar 同期の距離しきい値。 |
| `LowQualityDistance` | 20 | 低品質 avatar 同期の距離しきい値。 |
| `OverrideAutoDiscoveryOfIpv` | false | IP バージョンの自動検出ではなく、設定されたアドレスに正確にバインドします。 |
| `IPv4Address` | 0.0.0.0 | IPv4 バインドアドレス。 |
| `IPv6Address` | ::1 | IPv6 バインドアドレス。 |
| `Password` | default_password | サーバーアクセスパスワード。 |
| `UseAuth` | true | パスワード認証を有効または無効にします。 |
| `UseAuthIdentity` | true | auth 有効時に DID ID 検証を要求します。 |
| `BasisUserRestrictionMode` | Normal | 参加制限モード: Normal、BlackList、WhiteList。 |
| `HowManyDuplicateAuthCanExist` | 2 | 同じ auth ID に許可される同時接続数。 |
| `AuthValidationTimeOutMiliseconds` | 9000 | auth 検証タイムアウト（ミリ秒）。 |
| `EnableConsole` | true | 対話式サーバーコンソールを有効にします。 |
| `DisableWriteUnlessAdminPersistentFlag` | true | 呼び出し元が admin でない場合、永続 key/value 書き込みを拒否します。 |
| `DisableReadUnlessAdminPersistentFlag` | false | 呼び出し元が admin でない場合、永続 key/value 読み取りを拒否します。 |
| `UseNetworkFinalCompression` | false | 最終ネットワーク圧縮パスを有効にします。 |
| `EnableBSRProfiling` | false | Server Reduction System の profiling 出力を有効にします。 |
| `DisallowHeadless` | false | 接続時に headless クライアントを拒否します。 |
| `AvatarsLocked` | false | bypass 権限のないユーザーの avatar 読み込みをブロックします。 |
| `PropsLocked` | false | bypass 権限のないユーザーの prop 読み込みをブロックします。 |
| `WorldsLocked` | true | bypass 権限のないユーザーの world 読み込みをブロックします。 |

<small>公開設定フィールドと同じ名前の環境変数は、起動時にそのフィールドを上書きします。</small>

## 読み込み可能な設定ファイル

要求に応じて読み込むワールドとオブジェクトファイルを設定できます。
これらのファイルは`InitialResources`フォルダに配置します。

<Callout type="warn">
使用するリモートURLは、チャンキングをサポートする適切なサーバーから提供される必要があります。
</Callout>

<Callout type="info" title="アップロードするには">
Unityでシーンを作成し、BEEファイルとしてエクスポート、HTTPサーバーにアップロードし、URLを`CombinedURL`に、パスワードを`UnlockPassword`に設定します。
</Callout>

| 変数             | 定義 |
|------------------|------------|
| `Mode`           | 設定のモード：`0` = ゲームオブジェクト、`1` = シーン。 |
| `LoadedNetID`    | ネットワーク参照ID。 |
| `UnlockPassword` | リソースへのアクセスに必要なパスワード。 |
| `CombinedURL`    | `.BEE`ファイルへのURL |
| `IsLocalLoad`    | リソースがローカルから読み込まれるか、インターネットからかを示す。 |
| `Persist`        | スポーンしたプレイヤーがサーバーを去った後もオブジェクトは存在し続けるか？ |
