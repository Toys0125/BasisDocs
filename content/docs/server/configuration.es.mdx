### Compilar y ejecutar en Linux

#### Prerrequisitos para Debian/Ubuntu

Para Ubuntu 22.04:
`sudo add-apt-repository ppa:dotnet/backports`

Para Debian u otras configuraciones:

```
wget https://packages.microsoft.com/config/debian/12/packages-microsoft-prod.deb -O packages-microsoft-prod.deb
sudo dpkg -i packages-microsoft-prod.deb
rm packages-microsoft-prod.deb
```

Luego continúe la instalación:

`sudo apt-get update && sudo apt-get install -y dotnet-sdk-10.0`

#### Obtener Basis

Cambie a la carpeta deseada y ejecute:

`git clone -b long-term-support-20260425 https://github.com/BasisVR/Basis`

#### Compilar el servidor Basis

Abra una terminal y acceda al directorio: `cd Basis/Basis\ Server`

`dotnet restore`

Luego compile:

`dotnet build` (para depuración)

o

`dotnet build --configuration Release` (para release)

#### Ejecutar

Navegue al directorio BasisServerConsole y ejecute:

`dotnet .\BasisNetworkConsole.dll`

:::tip Para un release de Linux más específico

`dotnet publish -f net10.0 --self-contained --os Linux`

Desde `BasisServerConsole/bin/Debug/net10.0/BasisNetworkConsole` ejecute `./BasisNetworkConsole`.

:::

## Archivos de configuración

La primera vez que ejecute el servidor, se crearán varios archivos de configuración en el directorio del exe del servidor.

| Archivo/Carpeta          | Descripción                                 |
|--------------------------|---------------------------------------------|
| `config.xml`             | Archivo de configuración principal.         |
| `initialresources/`      | Contiene archivos de mundo y objetos que el servidor cargará a petición. |
| `Log/`                   | Carpeta donde se almacenan los registros del servidor. |
| `admins.xml`             | Lista de usuarios con privilegios de admin. |
| `banned_players.xml`     | Lista de cuentas de jugadores baneados.     |

## Config.xml

| Variable | Predeterminado | Descripción |
|---|---|---|
| `PeerLimit` | 65535 | Número máximo de peers conectados. |
| `SetPort` | 4296 | Puerto UDP en el que escucha el servidor. |
| `UseNativeSockets` | true | Usa llamadas de socket nativas del sistema operativo en lugar de la ruta administrada. |
| `NatPunchEnabled` | false | Activa NAT punch-through para introducir peers. |
| `PingInterval` | 1500 | Intervalo entre pings de mantenimiento, en milisegundos. |
| `DisconnectTimeout` | 30000 | Tiempo sin respuesta antes de desconectar un peer, en milisegundos. |
| `SimulatePacketLoss` | false | Descarta paquetes salientes artificialmente para pruebas. |
| `SimulateLatency` | false | Retrasa paquetes artificialmente para pruebas. |
| `SimulationPacketLossChance` | 10 | Porcentaje de pérdida de paquetes cuando la simulación está activada. |
| `SimulationMinLatency` | 50 | Latencia adicional mínima, en milisegundos. |
| `SimulationMaxLatency` | 150 | Latencia adicional máxima, en milisegundos. |
| `ReconnectDelay` | 500 | Tiempo antes de intentar reconectar. |
| `MaxConnectAttempts` | 10 | Número máximo de intentos de conexión. |
| `ReuseAddresss` | false | Opción de reutilización de socket; tenga en cuenta la ortografía del campo. |
| `DontRoute` | false | Opción de enrutamiento del socket. |
| `EnableStatistics` | true | Recopila estadísticas de transporte para informes de salud y estado. |
| `IPv6Enabled` | true | Activa soporte de sockets IPv6 dual-stack. |
| `MtuOverride` | 0 | Fuerza una MTU fija; 0 desactiva la sobrescritura. |
| `MtuDiscovery` | true | Activa la detección de Path-MTU. |
| `DisconnectOnUnreachable` | false | Desconecta al recibir ICMP unreachable. |
| `AllowPeerAddressChange` | true | Permite que el endpoint de un peer cambie durante la sesión. |
| `HasFileSupport` | true | Activa escritura de logs, listas de moderación, datos de identidad auth y otros datos en disco. |
| `HealthCheckHost` | localhost | Host o interfaz para health checks. Use * para enlazar a todas las interfaces. |
| `HealthCheckPort` | 10666 | Puerto TCP para health checks. |
| `HealthPath` | /health | Ruta del endpoint de health check. |
| `BSRSMillisecondDefaultInterval` | 50 | Intervalo base de envío del Server Reduction System, en milisegundos. |
| `BSRBaseMultiplier` | 1 | Multiplicador base aplicado antes del escalado por distancia. |
| `BSRSIncreaseRate` | 0.005 | Qué tan rápido crecen los intervalos de envío con la distancia. |
| `BSRSlowestSendRate` | 2.55 | Frecuencia de envío más lenta entregada a clientes para peers lejanos. |
| `HighQualityDistance` | 3 | Umbral de distancia para sincronización de avatar en alta calidad. |
| `MediumQualityDistance` | 10 | Umbral de distancia para sincronización de avatar en calidad media. |
| `LowQualityDistance` | 20 | Umbral de distancia para sincronización de avatar en baja calidad. |
| `OverrideAutoDiscoveryOfIpv` | false | Enlaza exactamente las direcciones configuradas en vez de autodetectar la versión IP. |
| `IPv4Address` | 0.0.0.0 | Dirección IPv4 de enlace. |
| `IPv6Address` | ::1 | Dirección IPv6 de enlace. |
| `Password` | default_password | Contraseña de acceso del servidor. |
| `UseAuth` | true | Activa o desactiva la autenticación por contraseña. |
| `UseAuthIdentity` | true | Requiere verificación de identidad DID cuando auth está activado. |
| `BasisUserRestrictionMode` | Normal | Modo de restricción de entrada: Normal, BlackList o WhiteList. |
| `HowManyDuplicateAuthCanExist` | 2 | Número de conexiones simultáneas permitidas para la misma identidad auth. |
| `AuthValidationTimeOutMiliseconds` | 9000 | Timeout de validación auth, en milisegundos. |
| `EnableConsole` | true | Activa la consola interactiva del servidor. |
| `DisableWriteUnlessAdminPersistentFlag` | true | Rechaza escrituras key/value persistentes si el solicitante no es admin. |
| `DisableReadUnlessAdminPersistentFlag` | false | Rechaza lecturas key/value persistentes si el solicitante no es admin. |
| `UseNetworkFinalCompression` | false | Activa la pasada final de compresión de red. |
| `EnableBSRProfiling` | false | Emite salida de profiling del Server Reduction System. |
| `DisallowHeadless` | false | Rechaza clientes headless al conectarse. |
| `AvatarsLocked` | false | Bloquea carga de avatares para usuarios sin permiso bypass. |
| `PropsLocked` | false | Bloquea carga de props para usuarios sin permiso bypass. |
| `WorldsLocked` | true | Bloquea carga de mundos para usuarios sin permiso bypass. |

<small>Cualquier variable de entorno cuyo nombre coincida con un campo de configuración público sobrescribirá ese campo al iniciar.</small>

### Configuración de autenticación




## Archivos de configuración cargables

Puede configurar archivos de mundo y objetos para cargar a petición.
Estos se colocan en la carpeta `InitialResources`.

<Callout type="warn">
Las URLs remotas deben ser servidas desde un servidor que soporte chunking.
</Callout>

<Callout type="info" title="Para subir algo">
Cree una escena en Unity, expórtela como archivo BEE, súbala a un servidor HTTP, luego coloque la URL en `CombinedURL` y la contraseña en `UnlockPassword`.
</Callout>

| Variable         | Definición |
|------------------|------------|
| `Mode`           | Modo de la configuración: `0` = Objeto de juego, `1` = Escena. |
| `LoadedNetID`    | Un ID de red de referencia. |
| `UnlockPassword` | Contraseña para acceder al recurso. |
| `CombinedURL`    | URL al archivo `.BEE` |
| `IsLocalLoad`    | Indica si el recurso se carga localmente o desde internet. |
| `Persist`        | ¿El objeto continúa existiendo si el jugador que lo creó abandona el servidor? |
